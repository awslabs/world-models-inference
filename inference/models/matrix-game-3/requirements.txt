# Upstream's own requirements (torch, diffusers, transformers, decord, ...) are
# installed from their repo in the Dockerfile. Do NOT duplicate them here: pip

# ships, which is what breaks flash-attn.
#
# What must be here is the serving layer. inference/lib/app.py imports FastAPI
# directly, and neither the NGC base image nor upstream's requirements provide
# it — the first deployment came up with the model weights staged, the image
# pulled, and the container dead on `ModuleNotFoundError: No module named
# 'fastapi'`.
